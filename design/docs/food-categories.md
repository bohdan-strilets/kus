# Категорії страв і іконки

45 категорій. Кожна позиція їжі (`FoodEntry`) отримує одну категорію — від неї залежить **лише іконка**,
калорії й БЖВ від категорії не залежать. Тому помилка AI тут дешева: гірша картинка, а не гірші цифри.

Іконки: `src/food/svg/<category>.svg` (viewBox 32) → `food-icons.generated.tsx` генератором `scripts/build-icons.mjs`; компонент `src/food/FoodIcon.tsx`, дошка — `mockups/brand-food-icons.html`.

## Як показувати

- **Картка страви в чаті:** іконка 28 у плитці 44 біля кожної позиції.
- **«Сьогодні», рядок прийому їжі:** іконка позиції з найбільшою калорійністю цього прийому (вечеря з піцою → піца).
  Рахує фронт з уже збережених записів, окреме поле не потрібне.
- **Рецепт:** категорія рецепта = категорія найкалорійнішого інгредієнта, якщо користувач не обрав іншу.
- Іконка декоративна (`aria-hidden`), бо назва страви завжди поруч текстом.
- Невідома або відсутня категорія → `plate`. Ніколи не порожнє місце.

Пограничні випадки, які варто додати в `packages/ai-eval`:
- «сирники» → `pancakes` (не `cottage-cheese`); «творог зі сметаною» → `cottage-cheese`;
- «капучино» → `coffee` (не `milk`); «протеїн на молоці» → `protein-shake`;
- «борщ» → `borscht`, «бульйон» → `soup`; «шаурма» → `fast-food`, «курка гриль» → `poultry`;
- «вареники з картоплею» → `dumplings` (не `potatoes`); «олія для салату» окремою позицією → `sauce`.
