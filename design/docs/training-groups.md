# Групи м'язів і запис підходів (тренування, з 0.10.0)

Одне джерело правди для моделі, бекенду й UI. Кожна вправа має **одну основну групу** з фіксованого списку — так само, як страва має одну категорію (`docs/food-categories.md`). Дошка — `mockups/training-groups.html`.

## Групи (порядок фіксований — так їх показуємо скрізь)

| Код (enum) | Підпис | Токени (тло / текст) | Значення |
|---|---|---|---|
| `CARDIO` | Кардіо | `muscle-cardio-bg` / `muscle-cardio-ink` | #E6F6C9 / #46592A (= carbs) |
| `CHEST` | Груди | `muscle-chest-bg` / `muscle-chest-ink` | #FDE6D3 / #7A3A10 (= hint-food) |
| `BACK` | Спина | `muscle-back-bg` / `muscle-back-ink` | #E2F0FB / #2F4A60 (= hint-training) |
| `LEGS` | Ноги | `muscle-legs-bg` / `muscle-legs-ink` | #E3F3EA / #0F5E40 (= hint-measure) |
| `SHOULDERS` | Плечі | `muscle-shoulders-bg` / `muscle-shoulders-ink` | #F1E7FA / #5A3A7A (= hint-advice) |
| `ARMS` | Руки | `muscle-arms-bg` / `muscle-arms-ink` | #FFF0C2 / #5E4508 (= hint-day) |
| `CORE` | Кор | `muscle-core-bg` / `muscle-core-ink` | #F3ECE3 / #4F4237 (= secondary / muted-strong) |

- Нових кольорів немає — `muscle-*` лише назви для наявних значень. Контраст тексту на тлі ≥ 6,5:1.
- **Кардіо** — у даних окрема гілка (`kind = CARDIO`: хвилини, дистанція, джерело ккал), а не група м'язів; в UI — плашка в тому ж ряду, першою.
- Плашка групи: padding 3 9, радіус 9, 12–13 / 700, тло й текст пари. Крапка групи: 7–10 px, колір `*-ink`. Іконок груп немає (і «м'язів» не малюємо).
- Іконка вправи: силова — `dumbbell` на тлі групи; кардіо — `run` (біг, доріжка), `bike` (вело), `rowing` (гребля), `walk` (ходьба), інше — `cardio`.

## Вправа → група

Правило: група — **те, що в цій вправі працює найбільше** (основний рух), а не всі задіяні м'язи. Складні рухи — за основним суглобом / рухом нижче. Окремої «Все тіло» немає.

| Група | Типові вправи (і варіанти назв) |
|---|---|
| Кардіо | бігова доріжка, біг, ходьба, велотренажер, вело, гребний тренажер, гребля, еліптичний тренажер, степер, сходи, скакалка, плавання, ВІІТ-кардіо |
| Груди | жим лежачи (штанга / гантелі / на похилій / на зворотному нахилі), жим у тренажері, розведення гантелей, кросовер, «метелик» (пек-дек), віджимання (у т. ч. з колін), віджимання на брусах |
| Спина | підтягування (будь-яким хватом), тяга верхнього блока, тяга горизонтального блока, тяга штанги / гантелі в нахилі, тяга Т-грифа, пуловер, гіперекстензія, «супермен» |
| Ноги | присідання (штанга, гантеля, гоблет, у Сміті), жим ногами, випади, болгарські присідання, станова тяга (класична, сумо), румунська тяга, розгинання / згинання ніг у тренажері, сідничний місток, hip thrust, відведення ноги, підйоми на носки, зашагування |
| Плечі | жим над головою (штанга / гантелі, стоячи / сидячи), жим Арнольда, махи гантелями в сторони, махи вперед, тяга до підборіддя, зворотні розведення, face pull |
| Руки | згинання рук на біцепс (штанга / гантелі / молот / на блоці), розгинання на трицепс (блок, француз. жим), жим вузьким хватом, віджимання від лави, згинання / розгинання зап'ястя |
| Кор | скручування, підйоми ніг (у висі / лежачи), планка (бокова теж), «велосипед», «російські скручування», ролик для преса, «мертвий жук», «птах-собака», нахили / повороти з вагою |

Спірні випадки (рішення 31.10):
- **Станова й румунська тяга → Ноги.** **Сідниці → Ноги.**
- Віджимання на брусах → Груди; жим вузьким хватом → Руки.
- Бурпі, свінг гирі, трастер, «фермерська прогулянка», кросфіт-комплекси → **найближча група за основним рухом** (бурпі, трастер, свінг → Ноги; фермерська прогулянка → Кор). Якщо модель не впевнена — питає однією кнопкою-вибором групи.
- Вправа, якої немає в таблиці, — модель обирає групу за цим правилом; людина може виправити словами («присід — це ноги»), і словник людини (`Exercise.muscleGroup`) запам'ятовує це для наступних разів.

## Підходи

- Силовий підхід — **вага (кг) × повтори**; з власною вагою — **лише повтори** (вага `null`). Час підходу (планка) — `durationSec`, показуємо «45 с».
- **Розминка** — окремий підхід з `isWarmup = true`: показуємо, але не рахуємо в робочі підходи, обсяг, рекорди й графіки.
- **Рекорд** — лише робочий підхід (найбільша вага для вправи; для власної ваги — найбільше повторів).

## Нотація (UI) — A + В (з 0.10.4)

Читаємо числа — **пігулки (A)**; правимо підходи — **таблиця (В)**. «×» — лише між вагою й повторами і завжди з «кг»; кількість підходів — словом.

| Випадок | Запис |
|---|---|
| Підхід | пігулка `70 кг × 5` (13–14 / 700, `track`, tabular-nums) |
| Однакові сусідні | пігулка `60 кг × 8` + `— 3 підходи` (`muted`) |
| Різні | пігулки поруч: `60 кг × 8` `65 кг × 6` `70 кг × 5`; згортаємо лише сусідні однакові |
| Розминка | пунктирна пігулка `розминка · 40 кг × 10`, 12 / 600 `muted`, перед робочими |
| Рекорд | пігулка `success-soft`, `70 кг × 5` 800 `success-ink` + `trophy` 13 |
| Власна вага | `8 повт.` `7 повт.`; однакові — `15 повт.` + `— 3 підходи` |
| План / шаблон | `3 підходи · 8–12 повт. · 60 кг` (власна вага — `· власна вага`), без «×» |
| Факт по плану | `3 підходи · 50 кг × 12`; «Минулого разу: 50 кг × 12 — 3 підходи» |
| Плитки | «Вправ 7» і «Підходів 22» — окремо, без «7 вправ · 22 підх.» |
| Живий режим і форма | таблиця: шапка «Підхід · Вага · Повтори» 12 / 600 `muted`, рядки `1 · 52,5 кг · 12 повт.`, розминка — «розм.» |
| Кардіо | `10 хв · 1,2 км` (дистанція — якщо є) |
| Ккал кардіо-вправи | лише назване: `180 ккал · з табло · на ціль не впливає` / `· зі слів` |
| Ккал тренування (з 0.10.3) | назване — `380 ккал · зі слів` / `· з табло`; інакше оцінка бекенду (MET × вага × тривалість) — `≈ 350 ккал · оцінка`, округлення до 10; змішано — `≈ … · оцінка`; немає ваги — нічого. До цілі не додається ніколи |

Десяткова кома: `67,5 кг × 5`. Пігулка не розривається (`white-space: nowrap`), переноситься весь ряд. Заборонено: `60×8 ×3`, `3×8–12`, `3 × 12 · 50 кг` — читаються двозначно. Відмінювання «підхід / підходи / підходів» і «вправа / вправи / вправ» — через `Intl.PluralRules('uk')`.
