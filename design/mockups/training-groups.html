Правила
Групи: правила (повний список вправ — docs/training-groups.md)Список лишаю ваш, з двома уточненнями: (1) «Кардіо» — це тип, а не група м'язів: у даних окрема гілка (час / дистанція / джерело), у UI — той самий ряд плашок для простоти; (2) «Кор» у UI коротше — «Кор» (прес, поперек, планка), якщо «Кор» задовгий на плашках.Сідниці → Ноги, станова / румунська тяга → Ноги . Окремої «Все тіло» не додаю: бурпі, свінг — у найближчу групу; так статистика за групами не розмивається.Кольори без нових токенів: пари з наявних — hint-* (п'ять) + carbs-bg/ink для кардіо + secondary/muted-strong для кору. Контраст тексту на тлі ≥ 6,5:1. Якщо закріплюємо — дати аліаси muscle-* на ці значення (лише назви, не нові кольори).Іконок груп немає (і не малюємо «м'язи»): група — текстова плашка або крапка кольору; вправа — dumbbell / run / bike / rowing / walk на тлі групи.Підходи: вага в кг × повтори; власна вага — лише повтори; розминка — окремий тип підходу (не в обсяг / рекорди / графіки).
