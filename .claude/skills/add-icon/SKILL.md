# Нова іконка інтерфейсу

Пак власний, Phosphor та інші бібліотеки іконок у проєкті не використовуються.
Джерело правди — SVG-файли; компонент `<Icon name>` генерується з них.

| Що                       | Де                                                             |
| ------------------------ | -------------------------------------------------------------- |
| SVG-джерела              | `apps/web/src/shared/ui/icon/svg/<name>.svg`                   |
| Генератор                | `apps/web/scripts/build-icons.mjs` (`pnpm --filter web icons`) |
| Згенероване (не правити) | `icon.generated.tsx`, `icon.preview.html`                      |
| Компонент                | `Icon.tsx`, для вкладки «Сьогодні» — `ProgressRingIcon.tsx`    |

## 1. Перевір, чи вона вже є

Відкрий `icon.preview.html` або `ICON_NAMES`. Часто підходить наявна (`chevron-right` замість «стрілки», `alert` замість «помилки»).
Не дублюй іконку під іншою назвою.

## 2. Назва

kebab-case, за змістом, а не за формою: `export`, а не `arrow-down-bar`. Активний стан вкладки — суфікс `-filled`.

## 3. Малюнок — правила сітки

- `viewBox="0 0 24 24"`, робоча зона 3…21, оптичний центр — 12,12.
- Кореневий тег рівно такий:
  `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.9" stroke-linecap="round" stroke-linejoin="round">`
- Лише лінії `stroke`, заокруглені кінці й кути. Радіуси прямокутників 2–4.
- Колір тільки `currentColor`. Заливка — лише `fill="currentColor"` (за потреби з `opacity`), виріз — `fill="var(--icon-cutout, #FFFFFF)"`.
- Жодних `id`, `<style>`, `<image>`, текстів, градієнтів. Товщину не задавай на елементах — її рахує компонент.
- Мінімум деталей: іконка має читатися на 18px. 2–4 елементи — норма.
- Стиль звіряй із сусідами: `camera`, `mic`, `chat`, `settings` — еталонні.

## 4. Згенеруй

```bash
pnpm --filter web icons
```

Генератор зупиниться з поясненням, якщо порушено правило (колір, id, viewBox, назва).

## 5. Перевір очима

Відкрий `icon.preview.html` і порівняй нову іконку з сусідами на 18 і 22px: та сама вага лінії, той самий розмір «маси».
Зроби скриншот і подивись його. Якщо іконка виглядає важчою чи меншою за сусідів — поправ малюнок, не товщину.

## 6. Використання

```tsx
<Icon name="export" size={18} />                       // декоративна, поруч є текст
<button aria-label={t('settings.export')}><Icon name="export" /></button>
```

Колір — класом тексту (`text-muted`, `text-primary`), не пропом.
