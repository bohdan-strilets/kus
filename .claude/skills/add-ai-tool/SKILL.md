# Зміна AI: інструмент, промпт, модель

Правила — розділ 6 `CLAUDE.md`.

## 1. Інструмент

1. Схема параметрів — zod у `packages/shared/src/ai/tools.ts`; опис для моделі — коротко, з прикладами значень.
2. Усе, що повертає модель, проходить zod **до** збереження. Відхиляти: ккал/г > 9.5, вага > 5000 г, від'ємні значення, дата в майбутньому, невідомий enum (категорія → `plate`).
3. Обробник на бекенді — у сервісі AI-модуля; цифри (підсумки, залишок) рахує бекенд, не модель.
4. Записи мають `source` (`label` | `memory` | `reference` | `estimate`), `confidence`, `assumption`.

## 2. Промпт

`packages/shared/src/ai/prompt.ts`. Тон: теплий, короткий, без сорому й моралі, без медичних порад і екстремальних дефіцитів; теми розладів харчування — м'яко, без цифр, з порадою звернутися до фахівця.
Уточнення — не більше 2 за раз і лише коли змінюють результат > ~100 ккал; навіть питаючи, модель записує найкращу оцінку.
Контекст: промпт + релевантна пам'ять + підсумок дня + кілька останніх повідомлень. Ніколи вся історія.

## 3. Eval — обов'язково

- `packages/ai-eval`: кейси на новий інструмент чи поведінку — типовий, пограничний, «не їжа».
- `pnpm --filter ai-eval eval` до і після; порівняй: нічого зі старого не просіло.
- Рядок у `PROMPT_CHANGELOG.md`: дата, що змінено, чому, результат eval.

## 4. Вартість і логи

Логуй модель, токени, вартість, тривалість, кількість викликів інструментів — без тексту повідомлень і фото.
Нова поведінка не має помітно збільшити токени на повідомлення; якщо збільшує — вкажи в звіті на скільки.
