# Рух і ефекти Kusik

Живе демо: `interactive/motion.html` (є перемикач «уповільнити ×3» і звук). Код: `src/motion` — токени й варіанти для Motion (`motion.tokens.ts`), `countUp`/`fillArc`, частинки (`celebrate.ts`), CSS лише для нескінченних петель (`motion.css`).

## Основа

| Токен | Значення | Для чого |
|---|---|---|
| `fast` | 120 мс | Натиск, зміна кольору |
| `base` | 200 мс | Поява бульбашок, перемикання вкладок |
| `slow` | 320 мс | Sheet, перемикач, капсула вкладки |
| `celebrateMax` | 1000 мс | Найдовше святкування |
| `ease-out` | `.2,.8,.2,1` | Усе, що з'являється |
| `ease-spring` | `.34,1.56,.64,1` | Живі відгуки: бейдж, хом'як, повзунок |
| `ease-in` | `.4,0,1,1` | Усе, що зникає |

Анімуємо лише `transform` і `opacity` (+ `stroke-dashoffset` для кільця, `height` для розкриття уточнення, `width` смужок).

## Каталог

### Відгук на дотик
- Кнопки, варіанти, чипи: `scale(.96)` на `:active`, fast (`PRESS`).
- Перемикач: фон base, повзунок slow + spring.
- Вибір варіанта: рамка й тло змінюються base.

### Чат
1. Повідомлення користувача: знизу 14px + opacity, base (`bubbleVariants`).
2. Індикатор «друкує»: голова хом'яка `think` + три крапки хвилею 900 мс (`.k-typing`). Мінімум 600 мс, щоб не блимав.
3. Відповідь Kusik: знизу 10px, base; рядки картки страви — каскад по 60 мс (`rowVariants`, `ROW_STAGGER_S`); ккал рахуються `countUp` 500 мс.
4. Бейдж «записано»: `popInVariants` (scale 0 → 1.25 → 1, 300 мс spring) + **рівень успіху 1** + звук `kusik`.
5. Уточнення: розкриття по висоті 250 мс (Motion `height: auto`); при виборі варіанта ккал перераховуються `countUp` 300 мс.
6. Шапка при скролі згортається у компактну смугу (`chat-compact`) — opacity + translateY, base.

### Навігація
- Капсула активної вкладки переїжджає за вибором (Motion `layoutId`), slow + spring; контент вкладки — з 8px праворуч, base (`tabContentVariants`).
- Sheet: знизу 320 мс out, закриття 250 мс in; скрим opacity (`sheetVariants` / `scrimVariants`).
- Перехід між екранами в стеку (профіль → пам'ять): з 8px праворуч + opacity, base. Без повноекранних слайдів.

### Дані
- Кільце калорій: від 0 до значення 700 мс (`fillArc`), число `countUp` 700 мс.
- Смужки макросів: ширина від 0, 600 мс, затримка 120 + i·80 мс (`BAR_FILL_MS`, `BAR_DELAY_MS`, `BAR_STEP_MS`).
- Анімувати лише при першому показі екрана за сесію і при зміні значення — не при кожному поверненні на вкладку.

### Стани
- Помилка в полі: трусіння 300 мс linear (`SHAKE_KEYFRAMES`), потім текст помилки з'являється з −4px, base.
- Поле росте з текстом: height fast, до 100px.
- Голосовий запис: стовпчики хвилі оновлюються кожні 90 мс з рівня мікрофона.
- Хом'як: кліпає раз на 4–6 с (150 мс), підскок 300 мс spring при зміні настрою, махання лапкою при `wave`.
- Лоадер: обертання 1.1 с, крихти з укусу; з'являється лише після 300 мс очікування.

## Три рівні успіху (чим рідше подія — тим яскравіше)

| Рівень | Подія | Візуально | Звук | Вібрація |
|---|---|---|---|---|
| 1 · Кусь | Кожен запис страви | Бейдж pop + 4 крихти вгору (точки + міні-пряник), 450 мс | `kusik` | 12 |
| 2 · Ціль дня | Калорії в нормі / білок добрано (раз на день) | Кільце дотягується, сяйво `success` 600 мс, 12 частинок колом (точки, риски, кільця), хом'як `happy` + підскок | `goal` | 15·60·15 |
| 3 · Досягнення | Серія днів, мінус кілограм (рідко) | Картка pop 380 мс, лічильник +1, 18 конфеті з пряниками й зірками падають, 1000 мс | `achieve` | 20·50·20·50·40 |

Конфіги частинок — `CELEBRATE` у `motion.ts`. Частинки — лише теплі кольори бренду (`#E58A45`, `#F2A877`, `#F7C59A`, `#B9521A`, `#F5C451`).
Рівень 2 і 3 — не частіше одного разу на подію (зберігай прапорець «вже святкували сьогодні»).

## Декоративні фони

- М'які розмиті кола (`filter: blur(28px)`, opacity .5) — на авторизації, splash, порожніх станах, лендингу.
- Дрібні «крихти» (кола 6–14px, кільця) навколо хом'яка в порожніх станах — статичні.
- У робочих екранах (чат, сьогодні, прогрес) декору немає — там дані.

## prefers-reduced-motion

- У корені `<MotionConfig reducedMotion="user">`; CSS-тривалості `--duration-*` → 0; `countUp`/`fillArc` одразу ставлять кінцевий стан.
- Частинок немає, лічильники показують фінальне число, хом'як не кліпає й не махає.
- Лоадер лишається, але обертається повільно (2.4 с) — інакше незрозуміло, що йде процес.
- Звук і вібрація при цьому працюють як завжди (це окремі налаштування).
