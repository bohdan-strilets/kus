# Компоненти Kusik

Розміри в px, кольори — назви токенів (`tokens.json` / Tailwind preset). Де є готовий код — вказано файл у `design/src`.
Точні значення завжди можна підглянути в HTML макета (інлайн-стилі).

## Каркас

### AppShell
- Тло `bg-app` (градієнт 165°), на всю висоту `100dvh`. Колонка `max-width: 480px` по центру.
- Шапка й нижня панель враховують `env(safe-area-inset-top/bottom)`.
- Бічний відступ (gutter) 16.

### BottomNav — 4 вкладки: Чат · Сьогодні · Прогрес · Рецепти
- Висота пункту ≥ 56, підпис 12/800, іконка 22 stroke 2.
- Активна вкладка: капсула 54×30, радіус 15, `primary-soft`, іконка й підпис `primary`.
- **Фірмова деталь — «укус»** на капсулі: два білі кружечки у верхньому правому куті
  (13×13 на top −5 / right −5 і 9×9 на top 3 / right −7). Тільки на активній вкладці.
- Неактивні: `muted`. Капсула переїжджає між вкладками (`.k-tab-indicator`, slow + spring).
- Крапка-бейдж на «Прогрес», коли готовий новий підсумок тижня (aria-label «Прогрес, новий підсумок тижня»).

### Header (чат)
- Лого-знак 28 + «kusik» + «· Понеділок, 5 жовтня» (muted); праворуч аватар 34 з першою літерою імені → профіль.
- Привітання за часом доби: «Доброго ранку / Добрий день / Добрий вечір, {ім'я}».
- **DaySummaryCard** під шапкою: напівкільце 112×70 (ккал з'їдено / ціль) + три MacroBar. Тап → «Сьогодні».
- При скролі вгору згортається у **CompactBar**: «1 370 / 2 200 · Б 78/140» (`chat-compact`).

### Header (внутрішні екрани)
- Кнопка «Назад» 44×44, радіус 22, `surface` 85% + `shadow-chip`; заголовок 24/800.

## Чат

### Bubble — користувач
- Праворуч, `max-width: 78%`, padding 11×15, радіус 20 20 **6** 20 (хвостик знизу праворуч).
- `primary` фон, білий текст 15/500, `shadow-accent`.

### Bubble — Kusik
- Ліворуч, перед ним **HamsterHead** 34 (`src/hamster`), настрій за контекстом: smile / think (друкує, уточнює) / happy / proud.
- Фон `surface-glass`, радіус 20 20 20 **6** (хвостик знизу ліворуч), текст `ink` 15/500, `shadow-card`.
- Мітка часу між групами: 12px `muted`, плашка `rgba(255,255,255,.6)`, радіус 10, по центру.

### MealCard (відповідь на запис їжі)
- Картка `surface`, радіус 24. Шапка: «Сніданок · 08:40» + плашка ккал (`primary-soft` / `primary-deep`).
- Рядки позицій: назва 14/700 + підпис 12 `muted` («3 шт · 150 г»), ккал праворуч 14/700. Розділювач `divider`.
- Позначки в підписі — посилання-підказки `primary` 12/600: «суха?», «як завжди».
- Підвал: «Б 23 · В 27 · Ж 17» 12 `muted` + кнопка «Редагувати» (34 заввишки, радіус 17, `button-secondary`).
- Бейдж «записано» — зелене коло з галочкою (`success`), з'являється `popIn` + звук `kusik`.

### ClarifyCard (уточнення)
- Розкривається під позицією (`expand`): питання + 2 варіанти-кнопки з ккал + чекбокс «Запам'ятати для …».
- Обраний варіант: рамка 2 `primary`, тло `primary-selected`.

### Suggestion card (порада)
- Рецепт усередині бульбашки Kusik: назва 14/700 + «540 ккал · 52 г білка», тап → рецепт.

### QuickChips (над полем вводу)
- Висота 36, padding 0 14, радіус 18, `surface` 85%, `shadow-chip`, 13/600. Горизонтальний скрол без скролбару.
- Набір фіксований: «Підсумок тижня», «Додати вагу», «Мої рецепти» (у новий день — звичні сніданки).

### InputBar
- Контейнер: `surface`, радіус 26, padding 6, `shadow-card`, gap 8.
- Ліворуч кнопка **камера** 42×42 (`button-secondary`), поле, праворуч **мікрофон** (порожнє поле) або **надіслати** (`primary`, 44×44, радіус 22).
- Placeholder: «Напиши, що з'їв, або спитай…». Поле росте до 5 рядків (~100px), далі скрол (`chat-long-input`).
- Голос: поле замінюється хвилею (`.k-voice-wave`) + таймер; звуки `micStart` / `micStop`.
- Фото: камера/галерея системним `<input type="file" accept="image/*" capture="environment">`.

### Typing indicator
- Голова хом'яка (think) + `.k-typing` (три крапки 7px, хвиля 900 мс).

### Error bubble
- Повідомлення користувача з позначкою «Не надіслано» (`danger`), відповідь хом'яка «ой» + кнопка «Спробувати ще».

## Дані

### CalorieRing / Gauge
- `success` дуга на треку `#F0E9E0`, кінці заокруглені. Число в центрі `big-number` tabular.
- Заповнення `fillRing` 700 мс, лічильник `countUp`. Закриття цілі → `ringGlow` + частинки + звук `goal`.
- 4 стани — `mockups/brand-calorie-ring-states.html`, екран — `today-over.html`:
  1. **До цілі** (< 97%): зелена дуга, у центрі «лишилось».
  2. **Ціль закрита** (97–103%): повна зелена дуга, галочка + «ціль дня закрита» (`success`), святкування рівня 2 раз на день.
  3. **Понад** (> 103%): зелена дуга повна, поверх неї з початку — другий оберт кольором `over` з білою прокладкою 2px
     (білий штрих на 4px ширший під дугою over). У центрі «+180» `over` + «ккал понад ціль». У шапці чату: «+180 понад».
  4. Друге коло не росте далі +50% (половина дуги) — далі говорить лише число.
- Перебір: без червоного, без звуку й вібрації. Анімація: зелена до кінця 700 мс → пауза 120 → over 400 мс ease-out.
- На «Сьогодні» під списком — картка хом'яка `support` (`primary-selected` тло) з конкретикою без моралі.

### MacroTiles / MacroBar
- Плитки 2×2 (профіль, план): радіус 16, padding 12, фон `macro.*.bg`, підпис 12/600 `macro.*.ink`, число 20/800.
- Смужки: висота 6, радіус 3, трек `#F0E9E0`, заливка `macro.*.bar`. Підпис «78 /140».

### WeekStrip (Сьогодні)
- Картка `surface` 70%, радіус 22, сітка 7 колонок. День тижня 12 `muted` + число 15/700 + крапка 6px.
- Крапка: `success` — день у нормі, `#C25A1C` (over) — перебір, біла — на вибраному дні.
- Вибраний день — темна капсула `ink`, текст білий, радіус 14. Стрілки ‹ › 44×44 для попереднього/наступного тижня.

### Charts (Прогрес)
- Вага: лінія `success` 2.5 з м'якою заливкою під нею, остання точка r6 з білою обводкою; сітка `divider`.
- Калорії за тиждень: стовпчики `primary` з радіусом 4 зверху, сьогоднішній (неповний) — `primary` 35%; пунктир цілі `#A8998A`; підпис над максимумом.
- Підсумок тижня в чаті: стовпчики дня в нормі `success`, перебір `#F2A877`, майбутній день `#DDCFC0`.
- Перемикач періоду 7 д / 30 д / 90 д — сегментований контрол (як Chip-група).

## Форми

### Button
| Варіант | Висота | Радіус | Фон / текст |
|---|---|---|---|
| primary | 48 | 24 | `primary` / білий 15/700, `shadow-accent` |
| secondary | 48 | 24 | `button-secondary` / `ink` 15/600 |
| dark | 48 | 24 | `ink` / білий (напр. «Перерахувати цілі») |
| danger | 48 | 24 | `danger` / білий (підтвердження видалення) |
| text | 44 | — | без фону, `primary` 14/600 (або `danger` для «Вийти») |
| small | 34–40 | 17–20 | `button-secondary` |
- Натиск `.k-press` (scale .96). Завантаження: `<Loader size={20} tone="onPrimary">` + текст дії («Зберігаю…»), `aria-busy`, `disabled`.

### Field
- Картка `surface`, радіус 16, padding 10×14, тінь `0 6px 16px rgba(80,50,20,.06)`. Підпис **всередині** зверху 12/600 `muted`,
  під ним input 16/600 `ink` (16px — щоб iOS не зумив), мін. висота 24. Поля стовпчиком з gap 10.
- Фокус: `inset 0 0 0 2px primary`. Помилка: `inset 0 0 0 2px danger`, підпис `danger`, текст під полем 12/600 `danger`, поле `shake`.
- Пароль — кнопка «показати» 44×44 праворуч.

### Choice (варіанти в онбордингу)
- Картка-кнопка: тло `field` (або `surface`), радіус 16–18, padding 14; заголовок 15/700 + підпис 13 `muted`.
- Обрано: рамка 2 `primary` + тло `primary-selected`.

### Chip (мультивибір «Чого не їси»)
- Висота 36, радіус 18; обрано — `primary-soft` + текст `primary-deep` + галочка.

### Toggle
- 52×30, радіус 15; вимк. `#DDCFC0`, увімк. `primary`; повзунок 24 білий, рух slow + spring.

### Consent card (реєстрація)
- Окрема картка з чекбоксом 22 і текстом у два рядки; посилання на політику `primary`. Без згоди — primary неактивна.

## Оверлеї

### Sheet
- Знизу, радіус 28 зверху, `shadow-sheet`, padding 10 16 28, хват 40×5 радіус 3 `#E2D6C9`, кнопка закриття 44 праворуч.
- Скрим `scrim` = `rgba(42,33,24,.4)`.
- `sheetOpen` 320 мс out / `sheetClose` 250 мс in. Закриття свайпом вниз і тапом по скриму.
- Використання: «Як я порахував», редагування запису, встановлення PWA.

### Dialog (видалення даних)
- Картка `surface` по центру, радіус 28, хом'як `oops` 90 зверху; заголовок 20/800, текст 15 `muted-strong` по центру.
- Посилання «Спершу експортувати дані» (`primary`, підкреслене), нижче дві кнопки в ряд:
  «Скасувати» (secondary) і «Видалити все» (суцільний `danger`, білий текст). Скрим як у Sheet.

## Стани

### EmptyState
- Хом'як 120–150 (`<Hamster mood=…>`), заголовок 20/800, текст 15 `muted` (max 30ch), одна primary-кнопка.
- Хом'як 140 декоративний (`label=""`), текст поруч усе пояснює. Настрій бери з макета відповідного порожнього стану.

### Loader (`src/brand/Loader.tsx`)
- Надкушений пряник обертається, без літери. Розміри 120 (екран) / 64 / 32 / 28 (у картці) / 20 (у кнопці).
- Показувати лише якщо чекаємо > 300 мс (`useDelayedFlag`).
