# Design tokens: what we added on top of `design/`

The source of truth is `design/tokens/theme.css` (Tailwind v4 `@theme`, read-only) with the
«when to use» notes in `design/tokens/tokens.json`. The code copy is
`apps/web/src/shared/ui/theme/tokens.css`: `theme.css` 1:1, plus the additions below. This page
lists every token that exists in code but **not** in `theme.css`, and why.

Rule (stage 1 decision): a value that repeats across `design/mockups` becomes a token. A value
used only once is rounded to the nearest existing token. Mockups win over `tokens.json`, and
`tokens.json` wins over `docs/*.md` (`design/CLAUDE-design.md`).

## Differences from `theme.css` that are not new tokens

- `--color-*`, `--radius-*`, `--shadow-*`, `--text-*`, `--ease-*` start with `initial`: Tailwind's
  defaults are dropped, so `rounded-2xl`, `shadow-lg` or `text-lg` can't bypass the design system.
  `white`, `transparent` and `currentColor` are declared back.
- `text-caption` and `text-small` carry weight 600. `theme.css` leaves the weight out, but
  `tokens.json` (`font.scale.caption`, `font.scale.small`) and the old Tailwind preset set it.

Surface transparencies from the mockups (0.45, 0.5, 0.6, 0.7, 0.82, 0.85, 0.94) are **not**
tokens: they are written with Tailwind's opacity modifier (`bg-surface/85`).

Durations (`fast` 120, `base` 200, `slow` 320) are plain `--duration-*` variables, as in
`theme.css`, because Tailwind v4 has no duration namespace: `duration-(--duration-base)`. Under
`prefers-reduced-motion` they drop to 0. Motion presets with the same values live in
`shared/lib/motion` (`DURATION_MS`, `EASE`, `TRANSITION`).

### Rules that follow from it

- Small text on `primary-soft`, `primary-selected` and text links straight on `bg-app` use `primary-deep`.
- Over-goal numbers and captions use `over-ink`. `over` is only for arcs, dots and bars.
