# Нова категорія страви

Категорія впливає лише на іконку — калорії й БЖВ від неї не залежать. Тому спершу подумай, чи не досить наявної.
Повний список і правила — `design/docs/food-categories.md`.

## 0. Чи потрібна нова?

- Якщо страва — різновид наявної категорії (сирники → `pancakes`), краще додати приклад у промпт, ніж нову категорію.
- Нова категорія виправдана, коли їжа часта у користувачів і жодна іконка її не описує.

## 1. Назва

snake_case, англійською, однина/множина як у сусідів: `dried_fruit`, `ice_cream`. Вона ж — значення enum у БД.

## 2. Скрізь, де живе список (усе в одному коміті)

1. `packages/shared/src/schemas/enums.ts` — додай у `FOOD_CATEGORIES`.
2. `apps/api/prisma/schema.prisma` — у `enum FoodCategory`; потім `pnpm --filter api prisma migrate dev --name food-category-<name>`.
3. `apps/web/src/shared/ui/food-icon/food.constants.ts` — група в `FOOD_CATEGORY_GROUP` (визначає колір плитки).
4. Локаль `uk` — `food.category.<name>`: коротка назва українською.
5. `packages/shared/src/ai/tools.ts` — рядок у описі поля `category`: `- <name>: 3–5 прикладів страв`.
6. `packages/ai-eval` — щонайменше 2 кейси: типовий і пограничний із сусідньою категорією.
7. `design/docs/food-categories.md` — рядок у таблиці (це дозволений виняток для `design/`).

Перейменування = нова категорія + міграція даних зі старої + видалення старої. Ніколи не перейменовуй значення enum на місці.

## 3. Іконка

Файл `apps/web/src/shared/ui/food-icon/svg/<name>.svg`:

- `viewBox="0 0 32 32"`, предмет у зоні 3…29, без плитки (плитку малює компонент).
- Плоскі заливки + контур 1.2 на тон темнішим кольором; 1 блік або деталь світлішим.
- Палітра — з наявних іконок (борошняне `#E8A85A`, м'ясне `#C0584A`, зелень `#7FBF5E`, жовтий `#F5C451`, кремовий `#FFF4E0`, білий посуд + `#E2C9B3`).
- Ракурс — збоку або 3/4, як у сусідів. Миски, тарілки, чашки — бери з наявних (`soup`, `pasta`, `coffee`).
- Без `id`, тексту, градієнтів.

Потім `pnpm --filter web icons`. Тип `Record<FoodCategory, …>` у `FoodIcon.tsx` не дасть забути SVG.

## 4. Перевірка
