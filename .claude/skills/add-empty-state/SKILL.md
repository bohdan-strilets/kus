# Порожній стан

Еталони: `design/mockups/today-empty.html`, `progress-empty.html`, `recipes-empty.html`.
Порожньо ≠ помилка: інший текст, інший хом'як, завжди дія, що веде далі.

## Склад (зверху вниз, по центру)

1. `<Hamster mood=… size={140} />` — декоративний (без `label`). Настрій: `hungry` — ще не їв, `think` — даних замало, `yum` — нема рецептів, `wave` — перший вхід.
2. Заголовок 20/800, `text-wrap: balance`, ≤ 40 символів: що зараз («Сьогодні ще нічого не записано»).
3. Текст 15/1.45 `muted-strong`, ≤ 2 речень: що з'явиться і як («Напиши в чаті, що їв, і тут з'являться…»).
4. Одна primary-кнопка 48px з дією, що веде туди, де дані створюються (зазвичай — у чат).
5. Тло екрана з м'якими колами й «крихтами» — як у макетах (декор лише на порожніх станах).

## Правила

- Тексти — через i18n, тон з `design/docs/brand.md`: на «ти», без докорів, конкретно.
- Без другої кнопки й без посилань «дізнатися більше».
- Не вигадуй функцію, щоб заповнити порожнечу: дія — лише наявна в застосунку.
- Для маленького блоку всередині екрана (не весь екран): хом'як 64–90, без декору фону, кнопка — `secondary` або текстова.
