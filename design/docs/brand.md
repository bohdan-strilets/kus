# Бренд Kusik

## Назва

- **Kusik** — від «кусь» (укус) + зменшувальне. Тепле, коротке, латиницею читається однаково всюди.
- У тексті: «Kusik» з великої. У лого й wordmark: **kusik** завжди малими.
- Чому не «Kus»: перевірили — у турецькій «kus» означає «блювати», в арабській/івриті звучить вульгарно. «Kusik» — без таких збігів.
- Домен: ще не куплено. Рекомендовано **kusik.app** (≈14 € перший рік, ≈25 €/рік далі; HTTPS обов'язковий — добре для PWA).
  Альтернатива — kusik.online (дешево на старті, дорожче далі). `.io` і `.ai` — дорого в продовженні.

## Логотип

- Знак: **надкушений пряник** — коло з трьома півколами-укусами вгорі праворуч, кремова «k» усередині.
- Градієнт 150°: `#FFB877 → #D45F22` («мутний», без різких переходів). Літера `#FFF4E6`, Manrope 800.
- Файли: `assets/logo-mark.svg`, `logo-mark-no-letter.svg` (≤ 20px і лоадер), `logo-mark-mono.svg` (одним кольором через `currentColor`),
  `logo-horizontal.svg` (знак + kusik), `favicon.svg`, PNG-іконки PWA. Літера в SVG-файлах перетворена на контур — шрифт не потрібен.
- Код: `src/brand/Logo.tsx` (`<LogoMark>`, `<Logo>`).
- Не можна: квадратна підкладка під знаком у UI (лише в іконці застосунку), інший кут укусу, обведення, тінь на знаку, плоский колір замість градієнта (крім mono).
- Іконка застосунку: знак на теплому градієнті `#FFF3E6 → #FBF5EC → #F1F2E6`, знак займає ~73% сторони; maskable — 58% (безпечна зона).

## Хом'як — обличчя застосунку

Тримає пряник-логотип у лапках. Пухкий, теплий, трохи сором'язливий. Не ментор і не тренер — друг, який рахує за тебе.

| Настрій (`mood`) | Назва | Коли |
|---|---|---|
| `wave` | Привіт | Перший запуск, онбординг, ранок |
| `happy` | Радіє | Ціль дня закрита |
| `think` | Думає | Уточнює порцію, Kusik друкує |
| `logged` | Записав | Страву додано (зелена галочка) |
| `support` | Підтримує | Перебір — без докорів |
| `surprised` | Здивований | «Ого, 900 ккал у салаті?» |
| `yum` | Ласує | Улюблений рецепт |
| `hungry` | Голодний | Нагадування про їжу |
| `proud` | Гордий | Серія днів, мінус кілограм |
| `remind` | Нагадує | Сповіщення |
| `oops` | Ой | Помилка, немає зв'язку |
| `sleepy` | Вечір | Підсумок дня ввечері |

- Повне тіло — `<Hamster mood>` (порожні стани 140, діалоги 90, онбординг). Голова — `<HamsterHead>` 34 біля кожної відповіді в чаті.
- Хом'як — SVG-компонент, не картинка: кольори, кліпання й махання лапкою — кодом, важить ~0.
- Живі дрібниці: кліпає раз на 4–6 с, махає лапкою при `wave`, підскакує при зміні настрою. Усе вимикається reduced motion.
- Не можна: малювати його іншим стилем, робити сумним/злим через їжу користувача.

## Колір — палітра «Хом'як»

| Роль | Колір | Правило |
|---|---|---|
| primary | `#B9521A` | Дії: кнопки, посилання, повідомлення користувача, активна вкладка. Білий текст на ньому 4.9:1 |
| primary-deep | `#8F3E12` | Натиск, текст на абрикосових плашках |
| primary-soft / selected | `#FCE6D2` / `#FDEBDB` | Капсули, плашки, вибраний варіант |
| ink / muted | `#2A2118` / `#6B5D50` | Текст. Теплі, не чисто-чорні/сірі |
| success | `#17845A` | **Тільки** успіх і дані: кільце, лінія ваги, «записано», дні в нормі, добрі новини |
| over | `#C25A1C` | Перебір у даних. Не червоний — перебір не помилка |
| danger | `#B42330` | Помилки й видалення. Навмисно червоніший за primary, щоб не плутати |
| macros | синій / зелений / персиковий | Білки / вуглеводи / жири — завжди ці кольори, завжди в цьому порядку |

Тло застосунку — теплий градієнт `#FCEBD8 → #FBF6EE → #EEF4E8` (165°). Ледь зеленуватий низ — навмисно, «свіжість».
Декоративні фони (м'які розмиті кола) — лише на авторизації, splash, порожніх станах і лендингу; не в робочих екранах.

## Типографіка

Manrope (400–800). Заголовок екрана 24/800, велике число 30/800 tabular, текст 15/500, підпис 13/600, мінімум 12/600.
Eyebrow-заголовки секцій: 12/700 UPPERCASE, трекінг 0.05em, `muted`.

## Голос і тон

- **На «ти»**, коротко, тепло. Як друг, що знається на їжі, а не лікар і не тренер.
- **Без докорів.** Перебір — «Буває. Завтра збалансуємо», а не «Ви перевищили норму». Ніякого червоного й «ой-ой» за їжу.
- **Конкретика замість мотивашок.** «Лишилось 830 ккал і 62 г білка. Курка з гречкою якраз закриє білок» — а не «Ти молодець!».
- **Чесно про точність.** «Вагу оцінив на око, тож поправ, якщо знаєш точніше», «≈ 150 г».
- **Питає лише те, що змінює цифру.** «Гречка суха чи варена?» — так; «Яка марка гречки?» — ні.
- **Пам'ять — тільки зі згоди.** «Запам'ятати: по буднях обідаєш на роботі?» → «Так / Ні».
- Помилки людською мовою: «Ой, не вдалося надіслати: немає зв'язку з інтернетом. Спробуй ще раз, коли зв'язок з'явиться.»
- Числа: «1 370 ккал», «82,4 кг», «−1,6 кг» (справжній мінус), «≈ −0,3 кг на тиждень».
- Слоган: **«Пиши, що їв. Решту порахую сам.»**

## Ключові рішення (уже ухвалені)

- Чат — головний екран; вкладки «Сьогодні / Прогрес / Рецепти» лише показують те, що створено в чаті.
- 4 вкладки, без вигаданих пунктів. Профіль — через аватар.
- Онбординг — у формі чату, 4 кроки, можна пропустити.
- Норма — формула Міффліна–Сан Жеора × коефіцієнт активності − дефіцит; «Як я порахував» показує формулу.
- Фото й голос — у тому ж полі вводу, а не окремими екранами.
- Звук «кусь» — підпис бренду: записав страву = хом'як кусьнув.
- Темна тема — пізніше.
